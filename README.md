# ClipForge AI – Website

Professionele landing page voor streamer-clippers.

## Inhoud
- `index.html` – de complete website
- `assets/hero-bg.jpg` – hero achtergrond
- `assets/dashboard-mock.jpg` – UI preview

## Lokaal openen
Dubbelklik op `index.html` of open hem in je browser.

## Gratis online zetten

### Optie 1 – Netlify Drop (snelst)
1. Ga naar https://app.netlify.com/drop
2. Sleep de hele map `clipstudio-pro` erin
3. Klaar – je krijgt direct een link

### Optie 2 – GitHub Pages
1. Maak een repo op github.com
2. Upload alle bestanden
3. Settings → Pages → Deploy from branch `main` → root
4. Site komt online op `https://jouwnaam.github.io/reponaam/`

## Features van de demo
- YouTube link plakken (live of VOD)
- Simulatie van AI-analyse
- Responsive design
- SVG logo
- Donkere streamer-esthetiek
